# Hyinit

Hyinit launches Hytale with Fabric Mixin and MixinExtras on Java 25.

- Server owners start with [Installing Hyinit](/mod/hyinit/installing-hyinit). [Troubleshooting](/mod/hyinit/troubleshooting) explains the launcher's messages.
- Plugin developers start with [Your first Mixin plugin](/mod/hyinit/your-first-mixin-plugin).
