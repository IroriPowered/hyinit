# Hyinit

Hyinit launches Hytale with Fabric Mixin and MixinExtras.

- Server owners start with [Installing Hyinit](/mod/hyinit/installing-hyinit). [Troubleshooting](/mod/hyinit/troubleshooting) explains the launcher's messages.
- Plugin developers start with [Your first Mixin plugin](/mod/hyinit/your-first-mixin-plugin), then read the [Conditions and manifest reference](/mod/hyinit/conditions-and-manifest-reference). Its [Version ranges](/mod/hyinit/conditions-and-manifest-reference#version-ranges) section shows how one JAR supports several Hytale lines.
