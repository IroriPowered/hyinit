# Hyinit

Hyinit launches Hytale with Fabric Mixin and MixinExtras on Java 25.

Run Hyinit instead of the server JAR. Put Mixin JARs in `earlyplugins`, not Hyinit itself.

- [Launching](Launching.md): commands, options and plugin discovery.
- [`manifest.json`](Manifest.md): metadata, dependencies and class loading.
- [Changelog](Changelog.md): changes and upgrade notes per release.
